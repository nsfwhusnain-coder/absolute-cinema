# Profile picture credits

## Characters

The Classics, Animals, Creatures, The Cast and Movie Night (`classic-*`, `animal-*`, `creature-*`, `cast-*`, `cinema-*`) were drawn for Absolute Cinema and are covered by the project's MIT licence. They are generated by `scripts/build-avatars.ts`; edit that file and run `bun scripts/build-avatars.ts` to change them.
